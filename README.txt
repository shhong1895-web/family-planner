Build 092 · 우리가족 플래너

업로드:
- index.html 교체
- sw.js 교체
- firestore.rules 교체 필요 (가족 사진 저장 권한 추가)

1) 이미 승인된 기기에서 "가족에 연결하기" 화면이 잠깐 보이는 문제
   - 확인해보니 이건 이미 이전 Build에서 고쳐져 있었습니다 (승인 여부를
     확인하는 동안은 조용한 로딩 화면만 보여주고, 확인이 끝난 뒤에야
     맞는 화면으로 넘어갑니다). 계속 보이신다면 배포가 안 된 옛날 파일을
     보고 계실 수 있으니, 화면 상단 Build 번호를 꼭 확인해주세요.

2) 환영 화면(👋 인사 화면)에 가족 사진 넣기 (신규)
   - "기기" 탭 맨 아래에 "🖼️ 가족 사진" 항목을 추가했습니다. 사진첩에서
     최대 4장까지 등록할 수 있고, 등록/삭제는 부모라면 누구나 가능합니다.
   - 사진은 용량을 줄여서(가로/세로 최대 640px) 저장하기 때문에 화질이
     아주 살짝 낮아질 수 있지만, 그 대신 데이터베이스 용량 제한에 안전
     하게 걸립니다.
   - 앱을 다시 열 때 뜨는 환영 화면 배경이 이제 등록해두신 사진 중
     하나가 무작위로 나옵니다 (등록 안 하시면 기존처럼 색 배경 그대로
     나옵니다).
   - 격려 문구 뒤에는 반투명 유리 느낌의 카드를 둬서, 사진이 무엇이든
     글자가 항상 또렷하게 보이도록 했습니다.

참고: 사진은 Firestore 문서 하나(meta/familyPhotos)에 다 같이 저장되는
구조라 4장이 현재로선 안전한 상한선입니다. 더 많이 넣고 싶다는 요청이
있으면, 그때는 저장 방식 자체를 다시 설계해드리겠습니다.
